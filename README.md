# TWIN — BIM-модели для застройщиков

Лендинг BIM-студии: один объект, два состояния. При скролле фасадный рендер
рассыпается на конструктив, инженерные системы и спецификации — и собирается
обратно при движении вверх.

Сайт статический: без сборки, бэкенда и базы. Всё, что нужно для запуска, —
`index.html`, `assets/` и любой HTTP-сервер.

## Запуск

```bash
python3 -m http.server 8099
# открыть http://127.0.0.1:8099/
```

Не открывайте `index.html` через `file://` — ES-модули и import map требуют
HTTP-контекста. Three.js и шрифты подгружаются с CDN, поэтому для первого
запуска нужен интернет.

## Структура

```text
index.html              разметка и весь текстовый контент
assets/css/style.css    визуальная система, адаптив, состояния morph / BIM
assets/js/main.js       прелоадер, скролл, меню, формы, счётчики, анимации
assets/js/scene.js      Three.js: башня, clipping-морф, BIM-слой, мини-сцены
assets/og.jpg           превью для соцсетей (1200×630)
web/                    старый демо-стенд G TON, не участвует в новом сайте
docs/                   старые материалы G TON Demo Day
```

`web/` и `docs/` оставлены как архив. На новый домен они не влияют: корневой
`index.html` уже отдаёт TWIN.

## Как устроен морф

- `#stage` — фиксированный fullscreen-canvas на весь сайт.
- Секция `.morph` занимает `340vh` (на мобильных `300vh`) и держит липкий экран.
- Скролл внутри неё превращается в прогресс `0…1` и передаётся в `scene.js`.
- Solid-здание обрезается плоскостью снизу вверх, а BIM-слой открывается
  встречной плоскостью. Так получается «сканирование» объекта.
- В BIM-слое: плиты, колонны, ядро, ВК / ОВ / ЭО / вентиляция, размерные линии,
  сетка, подписи LOD / IFC / QTO.
- При прогрессах `> 0.22` интерфейс переходит в тёмную BIM-тему; при
  прокрутке вверх — обратно.
- Проектные карточки — отдельные мини-сцены Three.js с вращением и drag.

## Что заменить перед публикацией

Сейчас в контенте стоят демонстрационные данные. Перед запуском заменить:

- название и логотип, если `TWIN` не финальный;
- почту `hello@twin.kz`, Telegram `@twin_bim`, телефон `+7 700 123 45 67`;
- адрес офиса;
- проекты `Atlas`, `Meridian`, `Orbita`, их метрики и подписи;
- цифры в блоке `.numbers` (38 объектов, 1.2 млн м², 11 лет);
- ссылку на политику конфиденциальности в футере;
- `assets/og.jpg` при смене визуала или названия.

Форма пока не отправляет данные на сервер: она собирает письмо и открывает
почтовый клиент через `mailto:`. Для реальной заявки подключите CRM / endpoint
в `main.js` (блок `Contact form`).

## Технологии

- Three.js 0.160 через import map и CDN unpkg.
- Процедурная геометрия: внешних GLTF/GLB-ассетов нет.
- Шрифты: Cormorant Garamond, Manrope, JetBrains Mono (Google Fonts).
- Никаких фреймворков, сборщиков и зависимостей в репозитории.

## Проверка

```bash
node --input-type=module --check < assets/js/scene.js
node --input-type=module --check < assets/js/main.js
```

Ручной чек-лист: hero на `1440×900` и `390×844`, морф в обе стороны, меню на
мобильном, отправка формы, отсутствие горизонтального скролла и ошибок в
консоли.

## Деплой

Подойдёт любой static hosting: Netlify, Vercel, Cloudflare Pages, S3 + CDN или
обычный nginx. Корень сайта — корень репозитория. Для SPA-роутинга ничего не
нужно: страница одна.
