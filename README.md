# MVP Twin Demo — цифровой двойник объекта (демо 24ч)

Демо-стенд под G TON Demo Day. Все данные выдуманные (`web/mock.json`).
Кнопки реальных интеграций — заглушки со статусом `в пилоте`.

## Запуск

```bash
cd web
python3 -m http.server 8080
# открыть http://localhost:8080
```
Без сборки, только статика. 3D — three.js с CDN (нужен интернет).

## Структура

* `web/index.html` — 3D башня 20 эт + слои ОВ/ВК/ЭО/вент + панели
* `web/app.js` — three.js: каркас, стояки, xray, разрез квартир, ночь, агент-заглушка
* `web/mock.json` — сети, здание, смета, датчики, обращения
* `docs/demo-scenario.md` — сценарий 5 минут

## Что реально, что stub

Реально: 3D башня, клик по этажу/стояку, слайдер этажей, X-Ray, разрез с квартирами, ночь, смета из мока, агент по 5 интентам.
Stub: кадастр PDF, IFC-загрузка, телеметрия, LLM-агент.
