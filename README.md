# MVP Twin Demo — цифровой двойник объекта (демо 24ч)

Демо-стенд под G TON Demo Day. Все данные выдуманные (`web/mock.json`).
Кнопки реальных интеграций — заглушки со статусом `в пилоте`.

## Запуск

```bash
cd web
npx serve . -p 8080
# открыть http://localhost:8080
```
Без сборки, только статика. Карта — MapLibre + OSM/Carto (нужен интернет).

## Структура

* `web/index.html` — карта + слои вода/тепло/свет + панели
* `web/app.js` — логика слоев, кликов, агента-заглушки
* `web/mock.json` — сети, здание, смета, датчики, обращения
* `docs/demo-scenario.md` — сценарий 5 минут

## Что реально, что stub

Реально: подложка, 3 слоя сетей (GeoJSON), клик-подсветка, смета из мока, агент по 5 интентам.
Stub: кадастр PDF, IFC-загрузка, телеметрия, расчет зоны <10 сек.
