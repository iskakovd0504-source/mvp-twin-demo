# Коммерция: 20-этажный ЖК (180 кв, ~14 200 м²) — twin под ключ

## Концепция одним абзацем
Один URL на объект: кадастр + 10 участков рядом → 3D-здание (клик = деньги/материалы) →
инженерия (клик = узел) → предиктив + FM-агент KZ/RU → чат жильцов с автовызовом мастера.
Строится — контроль, сдан — подписка УК. Тот же код масштабируется на район/город.

## Какие боли из 47 закрываем
Стройка/сдача: №5 (единая карта объектов), №20 (зона отключения ≤10 сек — у нас 3 сек),
№12 (поручения), №13 (голос), №4 (предикт рисков), №42 (перерасход), №21 (насосы).
Эксплуатация: №15–19 (ЕРЦ-квитанция), №6 (светоточки), №8 (мусор), №32–34 (ямы→109),
№7+№9 (паводок: сигнал+запас), №38 (деревья), №44 (пожарка — следующим шагом).

## Оборудование: стройка vs эксплуатация
- **Стройка:** 10 датчиков (ИТП подача/обратка, давление стояков, вибрация 2 насосов, уровень реки/ливневки), LoRa-шлюз на бытовке, планшет прораба. Данные → Twin Core → картина дня.
- **После сдачи:** + квартирные счетчики через УК (M-Bus), датчики паркинга (CO, затопление), пожарные извещатели в общую шину, камеры мусорки/двора → CV-статусы. Подписка покрывает связь и замену.

## Офер
- **Пилот 4 недели: ₸ 9 800 000** (маржа ~35%), вычитается из годового контракта.
- **Сборка twin под ключ (после пилота): ₸ 12–18 млн** (~1% сметы объекта, рынок BIM 0.5–2%).
- **Подписка: ₸ 180/м²/мес** (~₸ 2.5 млн/мес с дома) — предиктив, агент, чат жильцов, отчеты.
- Критерий приемки: 90% элементов с ценой, ответ агента <10 сек, 1 предотвращенная авария/перерасход.

## Рынок (окт 2026)
- **Autodesk Tandem** — мировой лучший по зданиям, но $$$, нет KZ-агента и кадастра РК.
- **Hexagon / Siemens** — промгиганты, не ЖК.
- **Matterport / Prevu3D** — красивые сканы без инженерии и смет.
- **PlanRadar (СНГ)** — документация и дефекты, без твина и предиктива.
- **THE ARK** — земля/дрон, не здания.
- **BIM-бюро РК** — модель под экспертизу за 0.5–1.2%, бросают после сдачи.
- **Мы:** единственные «кадастр→BIM→смета→датчики→агент→жилец» одним URL + KZ/RU + цена пилота. Обязаловка ТИМСО с 01.08.2026 — попутный ветер.
