# G TON → что строим и зачем

## Исходник
Реестр **47 задач** Smart City / GovTech / Industrial AI (Костанай: КТЭК, Тобол; Мангистау: Каспий, МАЭК).
Ядро кластеров: CV+Edge (дороги, мусор, свалки, парковки), предиктив (насосы, энергия),
GIS+Digital Twin (двойник КТЭК №20), GovTech (109 + Голос + Поручения).

## Наш выбор (заявка от aiprotocol.kz, материнская aitomaton.online)
1. **Digital Twin здания под ТИМСО** — главный коммерческий ход. С 01.08.2026 ТИМСО обязателен
   для госэкспертизы (школы 600+, техсложные), цель — 60% крупных предприятий с твинами к 2028.
   Продаем: `фикс за сборку твина (кадастр + BIM + смета + вьювер) + подписка ₸/м² за предиктив и FM-агента`.
   НЕ 5% от объекта — рынок 0.5–2%, иначе срежут на тендере.
2. **Ситцентр: 109 + Голос района + Поручения** — второй продукт на том же ядре
   (aiprotocol — аналитика обращений, aitomaton — задачи/голос). В MVP — как FM-агент + Картина дня.
3. Мусор/свалки — имиджево, но CV-железо, не наш профиль. Отложено.

## Что строит этот репозиторий (MVP к Demo Day)
Один URL, 3 слоя (урезано до кликабельного демо на моках за 24ч):
- **A. Земля (stub):** кадастр/скан — кнопками-заглушками «в пилоте».
- **B. Здание:** three.js ЖК 20 эт — клик по этажу/стояку = материалы + смета, X-Ray, разрез квартир, ночь.
- **C. Эксплуатация:** датчики (мок) + FM-агент 5 интентов (авария/перерасход/поручение/статус/уборка)
  + поручения + Картина дня. Голосовой ввод через Web Speech.

## Скоп по реке (зафиксировано)
Сигнал уровня + запас дома («выше паводка +1.3 м», оповещение за 72ч). Прогноз — из открытых
данных / Казгидромет API в пилоте. Свою русловую модель, размыв берега и сезонные сценарии
НЕ делаем — это научка на годы, не наш профиль. Формула со сцены: «Мы не предсказываем реку —
мы говорим дому, что с ним будет при таком уровне».

## Оффер со сцены
«Пилот 4 недели на вашем объекте: ваш IFC + ваша смета + 10 датчиков + FM-агент.
Фикс + подписка, сумма пилота вычитается из годового контракта.
Критерий: 90% элементов с ценой, ответ агента <10 сек, 1 предотвращенная авария».
