# Сценарий демо 5 минут (3D Twin ЖК 20 эт)

> Цель: за 5 минут показать «кадастр → здание → сети → квартира → агент → деньги».
> Всё на моках (`web/mock.json`). Реально: башня, клик этаж/стояк, слайдер, X-Ray, разрез, ночь, смета, агент 5 интентов. Stub: кадастр PDF, IFC-загрузка, телеметрия, LLM-агент.

## Подготовка (до выхода на сцену)

- Запуск: `cd web && python3 -m http.server 8080`, открыть `http://localhost:8080`.
- Проверить: интернет есть (three.js с CDN), слайдер этажей двигается, кнопки ВК/ОВ/ЭО/вент переключаются.
- Подготовить 2 вкладки: демо + `docs/commercial.md` (цены) на случай вопросов.
- Сбросить состояние: кнопка «Сброс демо» (demoreset) → ночь выкл, X-Ray выкл, разрез выкл, этаж 20, сеть ОВ.
- Закрыть лишние панели, открыть правую панель на блоке «Этаж» (d-floor).

## 0:00–0:40 — Башня: клик = деньги (40 сек)

**Показывает:** вращение мышью (OrbitControls, автовращение выкл при первом drag — крутить самому).
**Клики:**
1. Клик по плите среднего этажа → панель «Этаж N»: бетон/арматура/фасад/трубы/кабель + цена, подрядчик, % готовности (каркас/фасад/инженерия). Верхние этажи (15+) считаются с коэффициентом удорожания — показать эт 20 vs эт 5.
2. Слайдер этажей 20 → 1 → стилобат: камера сама едет к выбранному этажу (`controls.target`).
3. Клик по стилобату (n=0) → «коммерция, ИТП, насосная, паркинг −1, ₸ 410 млн». Клик по ядру (n=−1) → «3 лифта + лестница, стояки».

**Говорит:** «Каждый клик — это деньги и материалы. Этаж — плита, подрядчик, отставание. Стилобат и ядро тоже кликабельны. Данные выдуманные, логика — боевая: так сядет ваш IFC + смета».

## 0:40–2:10 — Сети: стояки, X-Ray, зона отключения (90 сек)

**Показывает:** 6 стояков в шахте (вода ×2, тепло ×2, свет, вент) + поквартирные ветки под потолком каждого этажа + вводы с улицы (синяя/красная/жёлтая трубы с запада).
**Клики:**
1. Кнопки слоёв ВК (синий) / ОВ (красный) / ЭО (жёлтый) / вент (фиолет) — лишние слои гаснут, выбранная сеть подсвечивается (`emissiveIntensity 1.25`).
2. Клик по цветному стояку в шахте → карточка сети (`netinfo`): линии, состояния («норма» vs авария), параметры.
3. Чекбокс X-Ray → фасад скрыт (`groups.facade.visible=false`), виден пучок стояков + разводка. Выкл — фасад вернулся.
4. Кнопка «Порыв» (blackout): расчёт зоны за 3 сек — «без тепла эт 14–20, 60 квартир» vs норматив 10 сек (задача №20 из gton-map). Стояки ОВ пульсируют 6 сек.

**Говорит:** «Фишка — нажимается и подсвечивается. Инженер тыкает в трубу и видит узел. Порыв — зона отключения за 3 секунды, это норматив акимата. Кровля: синие AHU — вент, оранжевый чиллер — тепло, всё кликабельно».

## 2:10–3:10 — Разрез + квартиры + ночь (60 сек)

**Клики:**
1. Чекбокс «Разрез» → верхние этажи сняты (`fn > n` скрыты), на выбранном этаже план: 4 квартиры A/B/C/D с цветными подложками пола + мебель (кровать/диван/кухня) + холл у ядра.
2. Клик по квартире → карточка: площадь, цена (коэффициент за высоту), статус (свободна/бронь/продана), квитанция MOCK (тепло/вода/свет), GUID `Apt-{этаж}{буква}`, кнопка «копировать».
3. Чекбокс «Ночь» → фасад светится тёплым (`emissive 0xffc873`), фонари по периметру включаются (PointLight), солнце гаснет. Выкл — день вернулся.

**Говорит:** «Разрез — это план продаж: квартира, цена, статус, квитанция. Ночь — проверка светоточек и витрина для покупателя. Продавцу — GUID квартиры, инженеру — стояки за стеной холла».

## 3:10–4:30 — Агент: 5 интентов + Картина дня (80 сек)

Агент — заглушка по ключевым словам (RU+KZ), полный LLM — «в пилоте». Ввод в поле `q` + Enter, есть чипы-подсказки и голос (Web Speech, только Chrome).
**Клики (вводить дословно):**
1. `где перерасход?` → подсвечивается ОВ + эт 17 + алерт «поручение наладчику ИТП, 24ч». (KZ-дубль: `шығын`.)
2. `статус` → Картина дня: каркас/фасад/инженерия факт/план + риски (ИТП, насос ХВС-2). (KZ: `мәртебе`.)
3. Если время: `авария` → ЭО, паркинг перегруз 91%, зона −1. `поручения` → открытых N, просрочено 2. `уборка` → поручение подрядчику.
4. Показать счётчик заданий и «Показать где» — камера летит к узлу/этажу, карточка пульсирует.

**Говорит:** «Агент понимает пять тем: авария, перерасход, поручения, статус, уборка — по-русски и по-казахски. Сейчас это правила на моках, в пилоте сюда встанет LLM с вашими регламентами. Ответ — подсветка на модели, не просто текст».

## 4:30–5:00 — Закрытие: ТИМСО + оффер (30 сек)

**Говорит дословно:** «ТИМСО обязателен с 01.08.2026 — эта модель уже проходит экспертизу. Пилот 4 недели на вашем объекте: ваш IFC + ваша смета + 10 датчиков + FM-агент. Цена пилота вычитается из контракта. Критерий приёмки: 90% элементов с ценой, ответ агента меньше 10 секунд, одна предотвращённая авария».
**Показать:** блок сметы (`estimate`: стадии, факт/план, отставания красным) + кнопка «Скачать CSV» → смета уходит в Excel. Роли (`dev/gos/inv/own`) — если спросят: инвестору — продажи, акимату — предписания, владельцу — квартира.

## Запасной план: нет интернета (3D с CDN не встанет)

Симптом: чёрный экран или «Не загрузилось» в шапке — three.js не скачался с CDN, сцена не строится.
1. Сразу сказать: «CDN недоступен — показываю по скриншотам и моку», не перезагружать 5 раз.
2. Открыть `web/mock.json` в редакторе: показать структуру (сети, смета, датчики, задачи, река) — «вот что крутит сцену».
3. Открыть `docs/commercial.md`: пройти по офферу (пилот ₸ 9.8 млн, сборка ₸ 12–18 млн, подписка ₸ 180/м²) и актуальности (Приказ №114, eserv.kz-стык).
4. Если есть заранее сохранённые скриншоты/видео демо — показать их; автоплей `demoPlay` без CDN всё равно не работает, не тратить время.
5. На будущее: скачать three.js локально (`web/vendor/three.module.js`) и поправить import в `index.html`/`app.js` — тогда демо работает офлайн.
