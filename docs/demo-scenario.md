# Сценарий демо 5 минут (3D-билд)

1. **Башня (30 сек).** Вращение → слайдер этажей 20→1 → клик по плите → смета этажа: бетон/арматура/фасад/трубы/кабель + цена. Стилобат и ядро кликабельны.
2. **Сети (90 сек).** Кнопки ВК/ОВ/ЭО/вент → клик по цветному стояку в шахте → карточка сети. X-Ray — скрыть фасад, показать пучок стояков. Фишка: `нажимается, подсвечивается`.
3. **Разрез + квартиры (60 сек).** Включить «Разрез» → верх снят, план этажа + 4 квартиры → клик по квартире → площадь/цена/статус + GUID. Ночь — фасад светится, фонари.
4. **Агент (90 сек).** Ввести `где перерасход?` → подсветка ОВ + эт 17 + поручение. Ввести `статус` → Картина дня: каркас 64%, фасад 38%, инженерия 22%, риски.
5. **Закрытие (30 сек).** Слова: `ТИМСО с 01.08.2026 — эта модель уже проходит экспертизу. Пилот 4 недели на вашем объекте, цена пилота вычитается из контракта.`
