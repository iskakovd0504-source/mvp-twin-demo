# Сценарий демо 5 минут

1. **Земля (30 сек).** Карта → контур участка → карточка: кадастр MOCK, статус чист. Кнопка `Кадастр PDF (в пилоте)` — показать, что слот есть.
2. **Сети (90 сек).** Включить Тепло → клик по Т-1 → подсветка + `перерасход +14%`. Включить Свет → Э-2 перегруз. Сказать: `нажимается, подсвечивается, зона видна`.
3. **Смета (60 сек).** Клик по корпусу → панель сметы: котлован/коробка/инженерия/сдача + отставание коробки. Кнопка `IFC-загрузка (в пилоте)`.
4. **Агент (90 сек).** Ввести `где перерасход?` → агент подсвечивает Т-1 + создает поручение сантехнику 24ч. Ввести `статус` → Картина дня: 3 риска, 2 просрочки, 1 кластер жалоб.
5. **Закрытие (30 сек).** Слайд-слова: `ТИМСО с 01.08.2026 — эта модель уже проходит экспертизу. Пилот 4 недели на вашем объекте, цена пилота вычитается из контракта.`
